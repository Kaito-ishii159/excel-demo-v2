# 産後ケア実施報告書 GitHub Pages版

千葉市産後ケア事業実施報告書【訪問型】を、iPhone / iPadで入力しやすいフォームにして、元のExcel様式へ反映してダウンロードする静的Webアプリです。

## GitHubへ配置するファイル

リポジトリ直下に、以下をそのまま配置してください。

```text
index.html
styles.css
app.js
template.xlsx
.nojekyll
vendor/
  jszip.min.js
  JSZip-LICENSE.md
```

`README.md`は公開しても問題ありませんが、ログインパスワードは書かないでください。

## GitHub Pagesの公開設定

1. Publicリポジトリを作成します。
2. 上記ファイルをアップロードして、`main`ブランチへCommitします。
3. `Settings` → `Pages`を開きます。
4. `Source`を`Deploy from a branch`にします。
5. Branchを`main`、Folderを`/(root)`にして保存します。
6. 表示されたURLを開きます。

## 主な機能

- 簡易ID・パスワード認証
- iPhone / iPad向け入力フォーム
- 入力内容をAES-GCMで暗号化した端末内自動一時保存
- 再読み込み・誤って閉じた場合の復元
- 元のExcel様式、書式、印刷設定を維持した出力
- Excelフォームコントロールのチェック状態反映
- GitHubや外部サーバーへの入力データ送信なし
- 外部CDN不使用
- CSS・JavaScript・Excelテンプレートを毎回最新URLで取得するキャッシュ対策

## 重要なセキュリティ上の注意

GitHub Pages自体は公開サイトです。このログイン機能はJavaScriptによる簡易的な閲覧抑止であり、サーバー側認証ではありません。HTML・JavaScript・空のExcelテンプレートは第三者が取得できる可能性があります。

- 実際の個人情報はGitHubに保存されません。
- 入力途中のデータはAES-GCMで暗号化し、利用端末のブラウザ内に保存されます。暗号鍵はログイン時のパスワードから生成し、同じタブのsessionStorageに一時保持します。
- 専用端末のパスコード、Face ID、OS更新、紛失対策を行ってください。
- OneDrive保存後はiPhone / iPad内のダウンロードファイルを削除してください。
- より強いアクセス制御が必要になった場合は、Microsoft Entra ID認証やAzure Static Web Apps等への移行が必要です。

## パスワード変更方法

パスワードの平文を`app.js`へ書かず、PBKDF2-SHA-256のソルトと派生キーだけを設定しています。変更する場合は、別途生成した以下3項目を`app.js`の`AUTH`へ設定します。

- `saltBase64`
- `derivedKeyBase64`
- `iterations`

IDは`AUTH.id`で変更できます。

## 動作確認

1. ログインします。
2. 必須項目を入力します。
3. 「Excelを作成・ダウンロード」を押します。
4. Windows版Excelで開き、文字・チェック・改ページ・印刷範囲を確認します。
5. iPhone / iPadでは、ダウンロード後に共有メニューからOneDriveへ保存します。

## 制限

- 一時保存は同じ端末・同じブラウザ・同じURLだけで復元できます。
- ブラウザのサイトデータを削除すると一時保存も消えます。
- 複数端末間の下書き共有や一覧検索はありません。
- Microsoft 365 / OneDriveへの自動保存は含まれていません。

## v4 修正内容

- 一時保存データをPBKDF2で生成した鍵とAES-GCMで暗号化
- 既存の平文一時保存データがあれば、ログイン後に暗号化形式へ自動移行
- 暗号鍵はlocalStorageへ保存せず、ログイン中のタブのsessionStorageに一時保持
- CSS、JavaScript、ExcelテンプレートのURLへ現在日時を付け、通常の再読み込みでも最新版を取得

暗号化は端末内に残る一時保存データの保護を強化するものです。ログイン中のタブが開いている間は復号用の鍵がsessionStorageに存在するため、専用端末のロック、紛失対策、OS更新は引き続き必要です。
